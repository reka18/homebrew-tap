# reka18's Homebrew tap

A personal [Homebrew](https://brew.sh) tap hosting formulae for reka18's projects.

```sh
brew install reka18/tap/<formula>
```

## Formulae

- **codesmith** — a terminal coding agent. → `brew install reka18/tap/codesmith` · [repo](https://github.com/reka18/codesmith)

_Each project is a separate formula under `Formula/`; installing one does not affect the others._
